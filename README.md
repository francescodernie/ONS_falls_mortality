# ONS_falls_mortality
Project looking at fall-related mortality and deprivation in England, 2002–2022

Project pre-registration on Open Science Framework: https://osf.io/cqauh/overview

Main data source: https://www.ons.gov.uk/peoplepopulationandcommunity/birthsdeathsandmarriages/deaths/adhocs/1355deathsbysexsingleyearofageunderlyingcauseicd10codeanddeprivationdecileengland2001to2022

For full project code, start by clicking on the folder 'falls-mortality-england' - this includes fuller details of the project, and analysis code to enable reproduction of the dataset and associated analyses
